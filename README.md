Calculadora simples

Descrição
- Projeto de uma calculadora básica feita com HTML, CSS e JavaScript.
- Suporta operações aritméticas simples: +, -, *, / e ponto decimal.
- Ajuste automático do tamanho da fonte para resultados longos.

Uso
- Abra o link: https://italosouzatech.github.io/Calculator/

Estrutura do projeto
- root/: página HTML principal.
- js/: lógica JavaScript da calculadora.
- css: arquivos de estilo.
- tests: (vazio) espaço para testes futuros.

Como contribuir
- Faça um fork, crie uma branch com a mudança e abra um pull request.
